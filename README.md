# 專科考題詳解


- 題目與官方答案：取自各學會公告的考古題/題庫
- 詳解：AI 撰寫，標 ⚠️(答案爭議)與(低信心)的題目請自行查證
- 作答紀錄：只存在瀏覽器(localStorage)，請定期匯出備份

## 開啟方式
- 線上：GitHub Pages 網址
- 電腦本機預覽：zip 完整解壓縮後，直接雙擊 index.html 即可(不要在 zip 裡面點開)。本機開啟的作答紀錄與線上版分開保存。

## 檔案
- `index.html`、`app.js`、`style.css`、`sw.js`、`manifest.webmanifest`：網站本體
- `data/banks.js`：題庫清單
- `data/*.js`：各題庫的題目與詳解(之後每批更新只需替換這裡的檔案)
- `img/`：題目附圖
