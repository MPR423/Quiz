# 決定與進度紀錄

新的決定或進度請加在對應段落（日期＋一行），不要刪舊紀錄。

## 範圍
- 急診專科考題（年度筆試卷，約 200 題／卷）＋外科專科題庫（台灣外科醫學會，依次專科分檔，總計約 1,000 題）。原檔只有答案，為每題寫詳解。
- 網站：GitHub Pages 靜態網站，手機瀏覽為主，可標記不熟題目。

## 已定案
- 語言：繁中為主，術語保留英文。
- 詳解深度依題型調整；格式見 `docs/style.md`（2026-10-07 pilot 經使用者審核通過）。
- 答案爭議：官方答案為正解；與現行證據不一致時寫 ⚠️ flag 說明，網站可單獨篩出。題目設計瑕疵但官方答案仍最佳時只寫在詳解內。
- 信心度：每題標高／中／低；只深入查證信心中低與指引敏感的題目。
- 出處：指引／教科書名稱＋版次，不寫頁碼；外科題庫的官方出題參考另外顯示。
- 分類：只分次專科。急診 20 類封閉清單、外科依檔案科別（`taxonomy.json`）。
- 圖片題：從 PDF 擷取原圖。
- 作答紀錄：存使用者瀏覽器（localStorage）＋匯出／匯入備份；iPhone 建議加入主畫面。
- PDF 上的螢光標記不匯入成「不熟」。
- 公開程度：完全公開；原始 PDF 也放在 repo 的 `sources/`（使用者決定）。
- 網站功能：測驗模式（答錯自動標不熟）／直接看答案、手動標不熟、篩選（題庫／次專科／未作答／最近答錯／不熟／⚠️／信心中低）、搜尋、各次專科正確率、匯出匯入、回報錯誤（開 GitHub issue）。複選題完全答對才算對。間隔重複（SRS）暫不做。
- 2026-10-07 pipeline：repo 為唯一真實來源；工作在 Claude Code 雲端 session 進行，由使用者手動開 session 觸發；直接 push 到 main，CI（build＋check）通過才部署，不另開 PR。
