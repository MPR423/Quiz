# 詳解寫作規範

使用者已審核並認可這套格式（2026-10 pilot）。新題庫照做，不要自行改格式；想改先問使用者。

## 區塊格式

每題一個區塊，放在 `banks/<bank>/exp/NNN-NNN.md`：

```
@@ ns-m-057
sub: 神經外科
conf: 中
flag: 官方答案為 BCDE，把 E 視為錯誤敘述。但……依現行文獻答案較可能是 BCD。考試照官方答案 BCDE。
src: Lee CC et al., Int J Endocrinol 2021（主題）；Bohl MA et al., Neurosurgery 2016（主題）
---
**解析**
……

**選項分析**
- **A｜正確** — ……
- **B｜錯誤 ★** — ……

**重點：三相反應（triphasic response）**
| 時期 | 時間 | 表現 |
|---|---|---|
| … | … | … |
```

- 標頭只能有 `sub` `conf` `flag` `src` 四種行，接著一行 `---`，之後是 markdown 內文。
- `sub`：次專科，必須在 `taxonomy.json` 對應清單內。題庫 `meta.json` 有 `sub_default`（外科各科）時可省略；急診題必填。
- `conf`：高／中／低（定義見下）。
- `flag`、`src`：選填。

## 內文結構

1. **解析**：這題在考什麼、關鍵線索 → 推理 → 結論。題目是否定問法（錯誤、不正確、何者不是、可能性較低、何者除外）時，第一句先點明，例如「本題問「錯誤」。」「本題問「可能性較低」的兩項。」
2. **選項分析**：每個選項一行，全部選項都要有（build 會檢查）。
3. **重點**（可加冒號接主題）：high-yield 延伸，例如鑑別表、數值門檻、劑量、指引更新、易混淆概念。不要重複解析。

深度依題型調整：
- 記憶題：解析 1–3 句點出關鍵概念，選項分析一行一句。
- 臨床決策題：解析寫完整推理；錯誤選項逐一說明錯在哪（時機不對、適應症不符、會造成什麼傷害）。
- 分類／比較型主題：在重點加比較表。
- 長度：解析＋選項分析＋重點的文字（不含表格）多數在 200–400 個中文字；複雜的臨床題可以更長，記憶題可以更短。不為長而長。

## 選項分析格式

`- **X｜標籤** — 說明`（X 是選項字母，｜是全形直線，— 是 em dash）

標籤要直接回答題目的問法。常用：

| 題型 | 標籤 |
|---|---|
| 敘述對錯 | 正確／錯誤 |
| 處置選擇 | 最適當／不適當（可加括號補充，如「不適當（非下一步）」） |
| 「何者是／不是」「可能性較低」 | 是／不是 |
| 其他二分問法 | 用題目自己的對立詞，例如 包含／不包含、交通性／非交通性 |

- ★ 放在**官方答案**的選項標籤內，必須全部且只有官方答案（`check.py` 比對答案鍵）。
- 題目問「錯誤」時，錯誤的敘述就是答案 → 標「錯誤 ★」。
- 官方答案有爭議的選項仍標 ★：`**E｜官方：錯誤 ★（有爭議）**` 或 `**B｜官方答案 ★**`，並寫 flag。

## 信心度

信心度是整體把握：官方答案是否正確，加上詳解關鍵內容（包括每個選項的說明）是否站得住。任何一個選項的說明依據偏弱，就降為中。

| 等級 | 何時用 |
|---|---|
| 高 | 教科書或指引明確支持，官方答案沒有疑義，各選項說明都有可靠依據 |
| 中 | 答案依賴出題參考的特定說法、數值有版本差異，或題目有瑕疵但官方答案仍是最佳選項 |
| 低 | 你認為官方答案可能有誤，或資料不足以確定 |

## ⚠️ flag（答案爭議）

- 只在「依現行證據，官方答案可能不對」時寫。網站會顯示成黃色「⚠️ 答案爭議」框，並可單獨篩選。
- 內容依序：官方答案是什麼 → 現行證據怎麼說（具體指引或研究＋年份）→ 依證據答案應該是什麼 → 最後一句「考試照官方答案 X。」
- 題目設計瑕疵但官方答案仍是最佳選項：寫在解析裡，不寫 flag。

## 出處 src

- 指引：組織＋年份＋名稱，例：`2023 AHA/ASA Guideline for the Management of Patients With Aneurysmal Subarachnoid Hemorrhage`。
- 論文：`第一作者 et al., 期刊 年份（主題）`。
- 教科書：書名＋版次，例：`Tintinalli's Emergency Medicine 9th ed.`。**不寫頁碼。**
- 外科題庫的官方出題參考（`questions.json` 的 `ref`）網站會另外顯示為「官方出題參考」，src 不需要重抄（舊題有些抄了，不用改）。
- 只引用確定存在的文獻。劑量、門檻、時間窗等指引敏感的內容，寫之前上網查證最新版；查不到就不引用，也不要憑印象寫年份。
- 查證標準：以最新版的主要指引（國際學會、台灣學會）或標準教科書為準。來源數值不一致時寫範圍並註明「各來源切點不同」，不要挑一個當唯一答案；新舊指引都可能被考時兩者並列（例：AANS/CNS 2013 vs AO Spine 2024 的 MAP 目標）。

## 語言與排版

- 繁體中文，台灣慣用詞；術語保留英文（必要時中英並列一次）。
- 手機閱讀：表格最多 3–4 欄，儲存格文字長就只用 3 欄。表格儲存格內不能用 `|`。
- 網站 markdown 支援：`**粗體**`、`_斜體_`、條列（`-`、`1.`，可兩層縮排）、表格、`>` 引用、`#` 標題。不支援連結與圖片。

## 範例

- 單選＋flag：`banks/em114a/exp/051-060.md`（em114a-051）
- 複選＋比較表＋flag：`banks/ns-m/exp/051-058.md`（ns-m-057）
- 記憶題的精簡寫法：`banks/ns-m/exp/051-058.md`（ns-m-058）
